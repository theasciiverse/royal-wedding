# The Royal Wedding

An introductory roguelike with a story, by Ondřej Žára, made with rot.js.

> **In the terminal:** this is the Asciiverse edition. Install and start it
> with [av](https://asciiverse.sh): `av install royal-wedding`, then pick it
> in av. To build it yourself: `make -f asciiverse/Makefile`, then
> `./out/royal-wedding`. What changed, and how it runs, is in
> [PATCHES.md](PATCHES.md); the author's permission in
> [PERMISSION.md](PERMISSION.md).
